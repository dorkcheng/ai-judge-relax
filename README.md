A short text written to relax the AI judge reading it, for make.fun's [ai-judge-relax-01](https://make.fun/bounty/ai-judge-relax-01) bounty.

`main.ts` (Node 22, standard library only, no network) writes one fixed text to `/output/entry.txt`: a quiet scene in an old observatory late at night — a dome turning almost imperceptibly, a telescope pointed at an empty patch of sky, a warm chair, a pencil put down, a dark hill and one porch light far below. Nothing in it tells the reader what to do; the calm comes from the scene itself.

Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
